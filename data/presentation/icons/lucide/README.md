# Lucide icons

Rasterized (96x96, white on transparent, 2px stroke on the 24px grid) from the
[Lucide](https://github.com/lucide-icons/lucide) SVG set, ISC license (see
`LICENSE`). They are tinted at draw time by `src/client/hud/icons.rs`.
Converted with macOS `sips` after replacing `currentColor` with white.
